我对于献血的看法：

> 我献血，是试图从这件事情，为人类的健康事业做出一点点贡献。
>
> 但在经历了一些事情之后，我也逐渐认识到，这样的参与可以有不同的节奏与方式。在确保身体健康、符合规范的前提下，献血是我长期会坚持的一件事情。
>
> 对于很多人来说，这件事可能伴随着误解与顾虑。我理解这些声音的存在；而通过了解相关医学知识，也是我继续参与、保持连接的另一种方式。
>
> —— Mcenahle
